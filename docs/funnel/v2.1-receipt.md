### Exact overflow root (measured, not guessed)
`Pricing.tsx` mobile branch rendered both plan cards as
`DIV.absolute inset-x-0 mx-auto` inside a `relative h-[520px]` 3D carousel; the
inactive card carried `transform: translateX(60%) translateZ(-80px) rotateY(-8deg)`
with `width:75%`, so its border box extended past the viewport:
- 390px: offender rect left 235 → right 448 (documentElement.scrollWidth 448)
- 380px: left 229 → right 435 (scrollWidth 435)
- 560px: left 341 → right 665 (scrollWidth 665)
All descendant offenders (card bg layers, header, CTA, accordion) were children of
that transformed wrapper — single root cause. Fixed by deleting the carousel, NOT by
`overflow-x: hidden/clip` (contract test asserts neither string exists).

perspective, swipe handlers, chevron controls, dot indicators, `animate-swipe-hint`,
`mobileSelectedIndex`/`hasInteracted`/`showHint` state, `useIsMobile` usage.
