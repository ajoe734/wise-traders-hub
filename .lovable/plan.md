# 老師每月薪資報表（隔月 5 號發放）

## 你會看到什麼
後台「對帳中心」新增一個「月結薪資」分頁：
- 最上方選月份（預設上個月），顯示「發放日：隔月 5 號」與整月總應發金額。
- 每位老師一張薪資卡：
  - 應發金額（大字）＝當月分潤 − 前期退款扣回
  - 當月有付款的學員數、付款筆數、淨收、平台留存
  - 若有退款扣回，另列一行「扣回 NT$X（N 筆，來自 X 月）」
  - 狀態徽章：未發放／已發放（日期、經手人）
- 卡片上「標記已發放」按鈕：按下後該月該老師鎖帳，數字不再變動；之後才發生的退款自動進下個月扣回。
- 可「取消標記」（需填原因，留稽核紀錄）。

```text
[2026/09 ▼]  發放日 2026/10/05   總應發 NT$ 48,200
┌ 彥愷 實戰導師 ───────┐ ┌ 阿倫 分析師 ────────┐
│ 應發 NT$ 23,960     │ │ 應發 NT$ 24,240     │
│ 學員 30 人／32 筆    │ │ 學員 28 人／28 筆    │
│ 扣回 −NT$ 560 (8月)  │ │                    │
│ [標記已發放]  未發放 │ │ 已發放 10/05 ✓      │
└────────────────────┘ └────────────────────┘
```

## 計算規則
- 歸月：依付款成功時間（台北時區）；年繳整筆算在付款當月。
- 金額來源：沿用現有分潤紀錄的「專家應分」，不重算比例。
- 退款：已發放月份的退款列為下月負項；未發放月份的退款直接從當月扣除。扣回後若為負數，顯示負數並延續到再下個月。
- 對帳警示：付款筆數與分潤筆數不一致時，在頁頂警示（沿用現有健康度檢查）。
