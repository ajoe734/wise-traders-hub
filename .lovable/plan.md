

# 收盤分析報告美化計畫

## 問題

目前收盤分析頁面有幾個視覺痛點：

1. **AI 策略分析**是純文字 `pre-wrap` 渲染，沒有用已有的 Markdown 元件，標題、粗體、列表全部擠在一起
2. 所有區塊外觀幾乎一模一樣（同色卡片 + 3px 左邊線），缺乏視覺層次
3. 今日損益摘要太小，無法第一眼抓住注意力
4. 異常波動、事件連動等區塊缺乏圖示提示，純文字密度太高
5. 歷史記錄展開後 AI 摘要被裁切 500 字且無 Markdown 渲染

## 改動項目

### 1. AI 策略分析改用 Markdown 渲染
- `FreeCheckup.jsx` 第 1847 行：將 `whiteSpace: pre-wrap` 的純文字替換為已有的 `Md` 元件
- 歷史記錄展開區（第 2034 行）同樣改用 `Md`
- 不需新增任何依賴

### 2. 今日損益摘要卡片放大 + 漸層背景
- 將損益數字從 `fontSize:20` 提升到 `28`
- 加入微漸層背景：漲時偏紅暈、跌時偏綠暈
- 加入日期徽章和更新時間的排版優化

### 3. 各區塊加入圖示 emoji 前綴 + 區塊間距優化
- 異常波動：⚡ 圖示 + amber 漸層頂部邊線
- 事件連動：🔗 圖示 + teal 漸層
- AI 事件評估：🧠 圖示 + blue 漸層
- 需要復盤：📋 圖示
- AI 規則驗證：🔬 圖示
- 策略大腦：🧬 圖示
- 卡片間距從 `marginBottom:10` 統一為 `14`

### 4. 持倉漲跌表格增加微型色條
- 每檔股票後面加一條細色條表示漲跌幅度，視覺上一眼看出哪檔波動最大
- 漲跌百分比字體略大、加粗

### 5. 分析中動畫優化
- 進度條改為漸層動畫 + 步驟文字加入淡入效果
- 加入脈動圓點動畫取代單調文字

### 6. 歷史記錄卡片優化
- 損益金額加入色底 pill 樣式
- 展開後 AI 摘要移除 500 字截斷限制，完整渲染 Markdown

## 涉及檔案

| 檔案 | 改動 |
|------|------|
| `src/pages/FreeCheckup.jsx` | 第 1786-2050 行的 daily 分頁渲染區塊 |

不需新增檔案，不需改動資料結構或 API，純前端渲染優化。

## 不動的部分
- 資料流、API 呼叫、localStorage/雲端同步邏輯完全不動
- 主題色系 `theme.js` 不動（已經很好）
- 其他分頁（holdings、events、news）不動
