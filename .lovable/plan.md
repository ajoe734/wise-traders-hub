# 改用官方「產業價值鏈」自動分類，減少人工核對

## 現成來源
- **櫃買中心「產業價值鏈資訊平台」（ic.tpex.org.tw）**：官方把各產業拆成上游／中游／下游，每一段直接列出公司，上市和上櫃都有。例如 PCB 鏈有「玻纖布、銅箔、CCL、PCB」等子項，富喬、建榮、德宏都列在玻纖。你要的分類就是這種。
- **公開資訊觀測站「主要經營業務」**：已經在用，拿來輔助判斷。
- **公司年報「產品營收比重」**：用來判斷多角化公司（台玻、南亞）的主業。
- FinMind 只有一般產業大類，不能當產業鏈依據。

## 要做的事
1. 先確認產業價值鏈平台的使用條款可以自動讀取，不行就改成每月人工下載匯入。
2. 每月抓一次全部產業鏈的「產業 → 上中下游 → 子項 → 公司」清單，存成分類依據。
3. 建一份對照表，把平台子項對到我們的 129 類（例如「玻纖布」對到「玻纖紗/玻纖布」）。對不上的子項列給你決定。
4. 自動採用規則：
   - 平台子項和主要經營業務一致 → 自動上線，依據寫「產業價值鏈：PCB 上游 玻纖布」。
   - 一家公司掛很多條鏈（多角化）→ 用營收比重決定主業；查不到比重就留待審。
   - 兩個來源衝突 → 留待審。
5. 用這個方法重跑目前 752 檔待審，只有符合規則的自動上線，其餘縮成短清單給你看。
6. 同業名單和估值抽屜跟著新分類更新。

## 驗收標準
- 富喬、建榮、德宏自動歸到玻纖，不用人工處理；台玻、南亞依營收比重判斷，判斷不了就留待審並寫出原因。
- 752 檔裡每檔都標出是「自動上線」「衝突」還是「來源沒有」，不抽樣。
- 平台子項全部有對照，或列在待你決定的清單裡。
- 相關測試全過；只改預覽，不發布正式站，也不部署後端。

## 技術細節
- 新增 Edge Function `refresh-industry-chain`：用 `fetchWithRetry` 讀平台，寫入新表 `industry_chain_membership`（symbol、chain、tier、sub_item、source_url、fetched_at）。新表會先給你看，取得同意才建立。
- 子項對照放在 `industryTaxonomy.json` 的 `chainSourceMap`，前後端鏡像以 contract test 鎖定一致。
- 純函式 `resolveChainClassification`（共用給 Vitest）：只輸出字典內的細分產業，衝突一律 `reviewed=false`，並沿用 `isAdoptedClassification`。
- 測試涵蓋：一致自動採用、衝突留待審、多角化看營收比重、對照不到的子項被丟棄。
