# 估值站牌清單：三個圖表模板（Preview 試看）

把截圖那 8 行價格（同業參考、上車站、下車安全帶、高壓站、前瞻低／參考／高、壓力測試）改成一張圖，手機一屏內看完。先做 Preview 試看頁讓你挑，正式抽屜不動。

## 三個模板（lieflat-charts）

**A｜站牌刻度尺（L7 Brand Spectrum）**
一條 NT$ 橫軸，8 個價位用短刻度標在軸上，名稱上下交錯排、不重疊；現價用橘點、成本用空心點。最省高度，約 90px。

**B｜三列啞鈴（F12 Dumbbell Queue）**
共用同一條 NT$ 軸，分三列：
- 歷史站牌：上車站 → 下車安全帶 → 高壓站
- 前瞻：前瞻低 → 參考 → 高（壓力測試標成虛線點）
- 同業：單點

現價畫一條縱線貫穿三列，一眼看出現價落在哪一段。約 140px。

**C｜刻度橫條（F5 Tick Rows）**
每個價位一行橫條，長度按價格排序，現價位置畫一條縱線穿過所有行，數字放在條尾。最好讀數字，約 200px。

## 共同規則
- 只用現有資料，不重算任何價格；缺值就不畫，不補假點。
- wire 灰階配一個橘色主角（現價），沿用抽屜的配色。
- 入場動畫：滾到才播、點擊重播，支援減少動態效果。
- 點一下價位會顯示完整名稱與數字，原本的「怎麼算」維持不變。

## 試看與驗證
- 試看網址：`/e2e/valuation-stations-templates?v=a|b|c`，只有 Preview 看得到；資料用你截圖這檔的真實數字。
- 在 390／380／560／768／1280 寬度截圖，確認沒有溢出、標籤不重疊、手機一屏內看完。
- 你選定後，再另外套用到正式抽屜。
