# 分類再細化：新增「市場族群」層＋拆細細分產業＋全市場重跑

## 現況（已查證）

- `stock_industry_map` 目前 2,527 檔，88 種細分產業，欄位只有：細分產業（最多 3 個）、營收比重、題材、信心度。
- 奇鋐 3017 現況＝產業「散熱模組／機殼結構件」、題材「AI伺服器／液冷散熱／輝達供應鏈」。雙鴻 3324、健策 3653 同為「散熱模組」。三檔都對，但看不出市場上講的「散熱三雄」。
- 題材白名單目前 40 個（AI伺服器、液冷散熱、CoWoS…），屬於「主題」而非「族群俗稱」，混放會讓兩種語意糊掉。
- 細分產業有些桶子太大：IC設計 135 檔、醫療器材 139、資訊服務 115、周邊設備 109、面板及零組件 99，同業中位數代表性仍不足。

## 一、新增「市場族群」層（與產業、題材並列）

字典新增第三類 `marketGroups`，收市場慣用的族群稱呼，例如：

- 散熱三雄、PCB 三雄、IP 三雄、ASIC 三雄、記憶體三雄、電源三雄、重電三雄、被動元件三雄
- 世界級概念群：CoWoS 概念股、輝達供應鏈概念、矽光子概念、液冷概念、低軌衛星概念、機器人概念、軍工概念、重電概念、無人機概念、AI PC 概念
- 傳產與金融：官股金控、壽險三雄、貨櫃三雄、散裝航運、觀光股、資產股、高息 ETF 成分權值

規則：

- 一律取自白名單，不得自由發明；每檔最多 3 個。
- 族群是「市場共識標籤」，不影響同業中位數母體（母體仍走細分產業），避免估值口徑被俗稱污染。
- 非個股（ETF／ETN／DR／權證）不進族群。

奇鋐預期結果：產業「散熱模組」、族群「散熱三雄、液冷概念、輝達供應鏈概念」、題材維持現狀。

## 二、細分產業再拆細

針對過大的桶子擴充字典（約 88 → 約 130 類），例如：

- 散熱模組 → 風冷散熱、液冷散熱、均熱片/VC、散熱風扇
- IC設計 → 電源管理IC、網通IC、驅動IC、觸控IC、MCU、影像處理IC、記憶體IC設計
- 醫療器材 → 體外診斷、影像醫材、植入式醫材、居家醫材、隱形眼鏡
- 資訊服務 → 系統整合、企業軟體、金融資訊、醫療資訊
- 周邊設備 → 影像裝置、輸入裝置、電競週邊、列印設備
- 面板及零組件 → 面板廠、背光模組、偏光板/彩色濾光片、觸控模組
- 另補：CoWoS/先進封裝服務、半導體檢測、載板（ABF/BT）、光學鏡頭、電源模組、伺服器機櫃

同業母體改用新的細分產業；某類同業不足 3 家時，自動退回其所屬大類（現在只標記 `peerScope` 沒有退回，這次一併補上），畫面照舊標示母體來源。

## 三、全市場 2,527 檔重跑

- 分類作業改為同時輸出「細分產業＋營收比重／題材／市場族群」，enum 全部限定字典值，超出即丟棄重判。
- 分批跑完全市場，寫入前後各做一次覆蓋率讀回（各類家數分布、未分類數、低信心數）。
- 既有的人工覆寫（`holding_meta_overrides`）與人工校訂檔優先序不變，重跑不會蓋掉人工結果。
- 重跑後保留舊快照一份，方便比對差異。

## 四、畫面

- 持倉抽屜與族群分佈：族群標籤獨立一排顯示（與產業、題材分開），純標籤不帶顏色語意。
- 族群篩選沿用現有篩選元件，多加一組「市場族群」條件。
- 後台「個股分類審核」頁可篩、可改族群，低信心優先排。

## 五、驗收

- 字典與判定純函式測試：族群白名單外一律丟棄；非個股不得有族群；每檔族群 ≤ 3。
- 覆蓋率讀回：分類筆數、族群筆數、各細分產業家數分布，確認沒有單一類別過度集中。
- 人工抽查 ≥ 60 檔，必含 3017 奇鋐／3324 雙鴻／3653 健策（散熱三雄）、3443 創意／3661 世芯／6533 晶心科（IP-ASIC）、2308 台達電、2317 鴻海、1101 台泥、2882 國泰金、2603 長榮，逐檔列出產業／族群／題材對照。
- 真實登入開持倉看板與抽屜，確認族群顯示、族群篩選、同業中位數改用新細分產業且不足 3 家時正確退回大類。
- 測試、型別、模組邊界、建置、安全掃描全綠。

## 技術細節

- 字典 `src/checkup/data/industryTaxonomy.json` 新增 `marketGroups: string[]` 與擴充後的 `groups`；Deno 鏡像 `supabase/functions/_shared/industryTaxonomy.ts` 由 contract test 鎖定一致。
- `src/checkup/lib/industryTaxonomy.ts` 新增 `isValidMarketGroup` / `sanitizeMarketGroups`（上限 3、去重、非個股回空）。
- DB：`stock_industry_map` 新增 `market_groups text[] default '{}'`，GIN index；RLS 沿用 public read / service write。
- Edge Function `stock-industry-classify`：輸出 schema 加 `marketGroups`，enum 限定字典；批次 20 檔、429/5xx 退避、失敗落地；modes `all`/`symbols`/`missing` 不變。全市場重跑走 `all`。
- `stockMetaMulti.js` 的 autoMap 層帶入 `marketGroups`；`useStockIndustryMap.ts` select 加欄位並 bump 快取 key 至 v2（避免舊快取缺欄位）。
- 同業母體：`valuation_snapshot` RPC 的 peers 查詢，細分產業命中 < 3 家時 fallback 到 `groupOfIndustry` 對應大類，回傳 `peerScope` 標示 fine/broad。
- 不動 BSR 管線、估值排程 110/111/113、寄信管線。
