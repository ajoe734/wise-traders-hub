# 確認是否有外部爬蟲

## 目前判斷
那 18,600 位大多不是外人來抓資料，而是我們自己的自動化測試。根據有三點：
- 很多訪客落在只有測試環境才有的頁面（`/e2e/*`、示範入口），外人不會知道這些頁面。
- 暴增的日期剛好是跑大量測試的日子，平常每天只有約 5 位訪客。
- 測試環境和正式站共用同一份流量資料，所以測試訪問被記成了訪客。

不過還沒逐筆排除外部爬蟲，所以這只是推斷，還不是定論。

## 要做的驗證
1. 查清理後剩下的 672 位訪客和近 7 天新進的訪客，依瀏覽器識別字串、IP 區段、出現頻率分組，找出 Googlebot、Bing、GPT、資料抓取工具等爬蟲特徵。
2. 查後端存取紀錄，看有沒有不經網頁、直接大量呼叫資料接口（報價、財報、持倉）的情況。
3. 回報結論：哪些是搜尋引擎（正常）、哪些是可疑抓取、哪些是測試殘留，並附上數量。

## 若發現可疑爬蟲（須你另外同意才做）
- 流量統計排除已知爬蟲識別字串。
- 對可疑來源加上請求頻率限制。

## 技術細節
- 唯讀查詢 `traffic_visits` / `traffic_events` 的 user agent 欄位，以及 edge/function logs，依 path 和 IP 彙總。
- 本計畫不改資料、不發布正式站。
