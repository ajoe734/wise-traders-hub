01 · 命名語意

legend 是「傳奇」，也是金融圖表的「圖例」。flow 是「流動」，也是順勢。合起來是「能讀懂市場圖例的順流者」。

06 · 不要這樣用

✕
不要把橘點換顏色 · 那個橘點是品牌核心識別。如果背景是橘色，把點換成墨黑 (#0B120E)；其他場景一律 #EC662D。
✕
不要拆開兩個字 · legend flow（中間空格）、Legend Flow（大寫）、legend-flow（連字號）都不可。
✕
不要用 Helvetica / Arial / Inter 等 sans-serif · 必須 serif。如果環境只有 sans，用 Source Serif 4 fallback 到 Georgia，不要落到 system-ui。
✕
不要加圖標、不要加箭頭、不要加 K 線 · 字標就是 logo，不要附加金融圖標元素。
✕
不要描邊 · serif 字本身的襯線就是質感，描邊會破壞。
✕
不要漸層 · 從來不漸層。實心色塊就是品牌。

08 · Code 引用方式

SVG 純檔放在 brand/ 資料夾。React component 範例：

// src/components/Brand/Logomark.jsx
export function Logomark({ size = 28 }) {
  return (
    <div style={{
      width: size, height: size,
      background: 'var(--ink)', color: 'var(--bone-soft)',
      borderRadius: size * 0.25,
      display: 'grid', placeItems: 'center',
      fontFamily: 'Source Serif 4, serif',
      fontWeight: 700, fontSize: size * 0.5,
      letterSpacing: '-0.04em', lineHeight: 1,
    }}>
      l<span style={{ color: 'var(--cta)', fontSize: '0.6em' }}>●</span>f
    </div>
  );
}

// src/components/Brand/Wordmark.jsx
export function Wordmark({ size = 15 }) {

    <span style={{
