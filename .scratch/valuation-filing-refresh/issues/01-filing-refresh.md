# 01 — 財報期限停用與公布更新

Status: needs-info
Priority: P1
Category: enhancement
Blocked by: 財報來源額度耗盡；真實新季完整財報及全產業原始欄位契約尚不可驗收。

## What to build

全股票共用期限與財報版本更新機制，讓持倉分級、抽屜站牌及同業倍數不再沿用過期推估。

## 驗收標準

- [ ] 台北期限當天仍可推估，隔天零時起 PE／PS 無新季報即資料不足，週末與行情日期落後仍生效；PB 不受此推估規則影響。
- [ ] 新季損益與資產負債資料同季完整才更新；提前公布不必等期限。
- [ ] 新季版號使抽屜／清單／同業讀到一致新版本；既有六小時快取不掩蓋更新。
- [ ] 尚未取得新季、錯誤、額度用盡保留待處理狀態；不能因更新 computed_at 而當作已完成。
- [ ] 全字典適用、無特定代碼分支；驗證所有季度期限、跨年、跨日、同業 PE／PB／PS、快取與失敗重試。
- [ ] 無 UI 排版改動；手機 560／390／380 同一日期判定。
- [ ] 公布來源與資料可取得時間需實測；無法保證供應商未提供的資料在公布當天到達，必須明示。

## 資料來源

**讀取**：官方公開財報索引（需驗證回應契約）、FinMind 損益／資產負債／月營收／股價、official_share_registry、stock_industry_map、同業名單、valuation_snapshot、valuation_peer_multiples。

**寫入**：後端限定的財報完整版本與更新狀態（實作時確定最小結構）、tw_sales_basis、tw_ps_daily、system_jobs_log；沿用權限邊界，不開放整表給會員。

**衍生規則**：沿用站牌數學與台北日界線；同業 PS 仍以實際近四季每股營收計算，禁止股價反推分母；財報來源、期別、版本、取得時間分開。

## Out of scope

- 不改 PE 60 倍／分散度／單季异常處理規則，不重寫未核准算法。
- 不發布正式前台、不建立重複 HTTP 排程、不修改現有排程認證。
