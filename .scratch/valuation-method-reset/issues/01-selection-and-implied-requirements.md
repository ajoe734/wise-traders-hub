# 01 — 持倉抽屜選尺與現價要求

Status: ready-for-agent
Priority: P0
Category: enhancement
Blocked by: None — can start immediately

## What to build

持倉抽屜不再把 PE／PB／PS 歷史帶交集當答案；逐尺揭露可用性、現價隱含條件與歷史／同業證據，個人只能選一把主要尺建立本機情境與壓力測試。

## 驗收標準

- [ ] 主價格軸不顯示三尺交集或系統合理價，只顯示現價、成本、分析師目標與一段個人情境。
- [ ] 財報分母可用時顯示現價隱含倍數、歷史範圍、樣本及同業可比性；不可用時顯示逐尺原因。
- [ ] 個人試算只允許一把主要尺，必填預期分母、倍數、來源、日期、假設、推翻條件與壓力參數。
- [ ] 舊多尺本機資料保留並要求確認，不靜默套用。
- [ ] 空資料、虧損 PE、後備股數來源均有明確文案。
- [ ] 320／390／桌面無溢出或標籤碰撞。
- [ ] 相關單元、渲染、型別、模組邊界與真實登入 Preview 驗證通過。
