# 01 — 持倉成交編輯及即時重算

Status: ready-for-agent
Priority: P1
Category: feature
Blocked by: None — can start immediately

## What to build
持倉可輸入新的持有股數和實際成交價格；以買進或賣出差額記錄真實交易，隨即反映持倉市值與三處估值。成本由歷史成交推算，修正既有成交價請在交易紀錄修正，不虛構交易。

## 驗收標準
- [ ] 股數增加／減少後交易紀錄新增相應真實成交，市值、產業、族群及投組估值即時重算。
- [ ] 同股數不虛構成交；錯誤價格、賣超、未登入不可提交，取消不修改任何資料。
- [ ] 560 / 390 / 380px 無溢出；既有測試及交易回歸通過。

## 頁面／路由清單
| 路由 | 新增／修改 | 准入條件 | 說明 |

| `/holding-checkup` | 修改 | 已登入可寫持倉 | 持倉抽屜編輯及即時統計 |

深連結與導向：從持倉卡進抽屜；唯讀／未登入不可提交；不更新 sitemap。

## 資料來源
**讀取**：帳號持倉 `pf-holdings-v2`，交易紀錄 `checkup_trade_memos`（僅本人）、同業估值既有唯讀 RPC。
**寫入**：既有 `pf-holdings-v2` 自動同步與 `checkup_trade_memos` 的本人交易紀錄；不寫帳務表。
**衍生規則**：股數，TWD 成交價；報價優先現有報價，不用成交價覆蓋；三處由同一持倉狀態即時重算，同業快照以代碼集合快取。

## Out of scope
不創造成本調整交易，不部署資料庫與後端函式；正式站需本人登入與操作真持股。
