# 01 — 正式持倉抽屜套用共用估值尺與法人身份色

Status: ready-for-agent
Priority: P1
Category: enhancement
Blocked by: None — can start immediately

## What to build

把 Preview 已確認的單一等比例 NT$ 估值尺與 Lieflat 三大法人灰階身份色移植到正式持倉抽屜，保留既有金融資料、情境試算、載入與錯誤邏輯，並讓所有尺寸與互動一致。

## 驗收標準

- [ ] 目標價、PE、PB、PS 共用一條等比例 NT$ 軸，以四段切換控制更新內容。
- [ ] 目標價模式顯示成本、現價與分析師目標；PE／PB／PS 模式只在該尺具備有效情境時顯示區間，否則明示原因且不畫假區間。
- [ ] 個人單尺情境仍只存在此裝置，套用後出現在對應尺模式；期間不一致與欄位缺漏仍阻擋計算。
- [ ] 三大法人摘要固定使用外資深墨、投信中灰、自營商淺灰；同一法人正負同色，方向由零線／正負號表達。
- [ ] 三大法人每日趨勢不再以紅綠表示正負；K 線與成交量既有台股紅漲綠跌維持不變。
- [ ] 載入、錯誤、空資料、部分 readiness、舊偏好與 reduced-motion 狀態正常。
- [ ] 560／390／380px 與完整既有斷點無溢出、標籤不重疊，切換與 scrubber 可操作。
- [ ] 既有測試全綠，並新增單元與 E2E 測試涵蓋估值切換、資料不足、法人固定色與所有必要尺寸。
